# Friendship Compatibility Analyzer

## Problem Statement
In academic and social settings, students often look for a fun and interactive way to check the friendship strength or compatibility between two people based on their names. Most existing tools are either web-based, lack proper programming structure, or do not demonstrate the use of fundamental concepts such as lists (arrays), modular design, and GUI development.

This project aims to solve that need by creating a desktop application that calculates friendship compatibility using list-based letter processing, provides a clear visual result, and maintains a history of previous checks.

## Scope of the Project
- Desktop GUI application developed in Python using Tkinter
- Input of two names
- Validation of user input
- Compatibility calculation using lists (arrays)
- Display of percentage score and friendship message
- Storing and viewing previous results (history)
- Basic error handling and clean user interface

**Out of Scope:**
- Internet connectivity
- User login / authentication
- Advanced machine learning
- Mobile application

## Target Users
- First-year engineering students
- Teachers (for demonstration purposes)
- Anyone who wants a simple and fun name-based friendship checker

## High-level Features
1. Clean graphical user interface
2. Name input and validation
3. Friendship percentage calculation using lists
4. Result display with friendly messages
5. History of previous calculations
6. Clear / Reset functionality
